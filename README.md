# REALM v3 — Isometric city prototype

This version replaces the dashboard feel with a clickable isometric-style city map.

## Update your GitHub Pages game
1. Download and unzip this package.
2. Upload/replace `index.html`, `style.css`, `game.js`, and `app.js` in the root of your existing GitHub repository.
3. Commit changes and wait for Pages to publish.
4. Refresh your game. If the old version remains, clear cache or hard-refresh.

## Play
Tap a parcel on the map, buy it, select a compatible building plan, then use End day to advance construction and daily finances. City services and financial reports are available from the right-side actions. The save is local to the current browser/device.

This is a lightweight browser prototype using CSS-drawn building art, not a true 3D engine. Values are fictional. No accounts, multiplayer, cloud saves or real payments.
